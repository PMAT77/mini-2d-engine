# 空手拳击

Tab 开关背包，B 不再绑定；滚轮切换枪械，C 收枪／拔枪。空手按住右键面向鼠标并摆出屈肘抱架，再逐次点击左键出拳。长按左键不连打，先按左键再按右键不会出拳。抱架不提供格挡。

X 是一次点击，短暂停顿记为 `-`。相邻点击间隔 ≤240ms 算快连，240～550ms 算停顿，>550ms 重新起手。首拳立即开始，最多缓存两拳，不等待整套输入收齐。

| 节奏 | 动作 | 基础伤害 | 体力 |
| --- | --- | --- | --- |
| XXX | 左刺拳 → 右直拳 → 左摆拳 | 8 / 12 / 16 | 3 / 4 / 5 |
| X-XX | 左刺拳 → 右摆拳 → 左上勾拳 | 8 / 12 / 20 | 3 / 4 / 6 |
| XX-X | 左刺拳 → 右直拳 → 右重直拳 | 8 / 12 / 24 | 3 / 4 / 7 |

前两拳持续 240ms，终结拳分别为 300 / 360 / 420ms；动作 40% 时结算一次命中。普通拳冲量 100，终结拳为 180 / 220 / 280。范围从角色中心计算 64px，摆拳总角度 110°，其他拳 70°；计入目标半径一次，只打中最近且无地形／静态障碍遮挡的有效目标。

伤害沿用攻击增益，视为身体近战命中，没有爆头倍率。鸡和丧尸共用既有受击、击退、死亡和掉落流程；丧尸击杀计普通击杀积分。

体力在每拳实际起手时扣除，同时重置恢复延迟；不足时清空后续输入，不会在恢复后自动出拳。单击、双击各自完成，连续两次停顿从第三次点击重新开始刺拳；终结拳收招期间不接受新一链。

松开右键、翻滚、切装备、开面板、失焦和死亡均清空当前拳及缓存，未结算命中取消，已消耗体力不返还。保留原有移动，不产生额外突进。程序动画读取玩法控制器的同一份动作进度。

参数集中在 `src/combat/PlayerPunchController.ts`。新 HUD 素材及完整生成提示见 `public/assets/images/weapons/fist-left-v1.source.md`。验证命令：`npm test`、`npm run typecheck`、`npm run build`、`npm run test:boxing-browser`。
