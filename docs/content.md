# 内容设计

> 本文定义敌人、战利品、关卡与节奏。
> 规则公式与数值口径见 [规则与数值](rules.md)。

## 1. 敌人设计卡

### 巡逻兵

- 定位：基础压力，教会玩家关灯与绕背。
- 生命 60，移速 3 格/秒，视锥 60°，视距 12 格，听觉系数 1.0。
- 行为：沿固定路线巡逻，路口停留 1.5 秒。发现目标后点射，并呼叫增援。
- 反制：关灯绕背、丢石子、背后 1.5 倍伤害。
- 掉落：手枪弹、钥匙卡（低概率）。

### 猎犬

- 定位：惩罚龟缩与流血。
- 生命 30，移速 4.5 格/秒，无视光照，嗅觉 10 格，血迹 15 格。
- 行为：循气味直线逼近。扑击前摇 0.3 秒。
- 反制：涉水消除气味、关门、远程击杀。
- 掉落：无。

### 探照灯

- 定位：地形控制，制造不能走的区域。
- 生命 20，固定光锥 30°、15 格，扫描周期 6 秒。
- 行为：缓慢摆动。照到玩家后向全层报警。
- 反制：断电 3 秒、打灭、贴阴影走。
- 掉落：无。

### 重甲兵

- 定位：强制换手段。
- 生命 200，移速 2.5 格/秒，正面减伤 80%。
- 行为：直线推进，近距射击。转身慢。
- 反制：爆炸、陷阱、绕后、关门。
- 掉落：护甲板、重武器零件。

## 4. 房间类型与关卡结构

| 房间 | 作用 | 战利品密度 | 风险 |
| --- | --- | --- | --- |
| 入口 | 出生，无敌人 | 无 | 无 |
| 走廊 | 连接，伏击点 | 低 | 中 |
| 仓储 | 主要搜刮 | 高 | 中 |
| 控制室 | 断电、开门 | 中 | 高 |
| 宿舍 | 补给与情报 | 中 | 低 |
| 医疗 | 治疗与药品 | 中 | 低 |
| 泵房 | 积水，改变声音 | 低 | 高 |
| 撤离平台 | 终点 | 无 | 极高 |

连接规则：

- 每个房间 2～4 个出口。
- 至少 1 条环路，避免纯树状。
- 高价值房间放在死胡同，用风险换收益。
- 出生点到撤离点至少 2 条路径。

## 5. 一局节奏

| 时间 | 事件 | 玩家感受 |
| --- | --- | --- |
| 0～1 分 | 进入，只有环境音 | 安静，观察 |
| 1～3 分 | 首次接触巡逻兵 | 紧张，学习规则 |
| 3～6 分 | 搜刮高峰，警戒上升 | 贪婪与不安 |
| 6～9 分 | 增援抵达，撤离点开启 | 压力 |
| 9～12 分 | 撤离窗口收紧 | 决断 |

超过 12 分钟，增援间隔缩短到 60 秒，逼迫撤离。

## 6. 可重玩性来源

1. 站点布局：房间顺序、出口、死胡同。
2. 战利品分布：高价值物品随机落在 2～3 个候选房间。
3. 敌人组合：巡逻兵、猎犬、重甲兵的比例随威胁等级变化。
4. 撤离条件：明点、暗点、限时点。
5. 天气：雨声掩盖脚步，雾降低视野，风影响声音方向。
6. 委托：可选目标，改变路线与风险。

## 7. 经济与内容预算

- 一局平均带出价值 300～800。
- 装备价格 200～1500。
- 蓝图解锁价 500～2000。

首个可玩版本的内容预算：

| 内容 | 数量 |
| --- | --- |
| 敌人 | 1 种（巡逻兵） |
| 房间套件 | 4 种 |
| 战利品 | 6 种 |
| 消耗品 | 4 种 |
| 站点主题 | 1 个 |
| 撤离点 | 2 个 |

完整版目标：4 种敌人、5 套房间、30 件战利品、12 件工具、4 个站点主题、20 个委托。
