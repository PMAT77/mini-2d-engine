## 1. 验收结论

普通丧尸与跑尸、声音调查、视觉确认、记忆追踪和搜索、近战、枪击打断、独立击退、尸体阻挡收尾、感染、两剂地图疫苗、E 拾取、V 治疗、F2 世界/音频暂停和死亡返回菜单已接通。六项锁定决策均落地。

功能与结构性预算检查全部通过：548 项 Node 测试、类型检查、生产构建、20 个既有浏览器脚本、11 组丧尸专项、生产模式检查及 10 档性能采样。没有跳过或关闭原有断言。

**性能目标分别判定：** 默认 4 只丧尸的 AI/导航 P95 在两个 DPR 下均为 0.3ms，满足 2ms 目标；当前 SwiftShader 软件渲染环境的整帧 16.67ms 目标没有达到，0 只丧尸对照同样超出。50/100 只为压力档，未宣称达到 60 FPS。GPU 与 GC 时间没有直接观测，均为不可用。

## 4. 覆盖范围

### Node 与引擎回归

- 命中：纯最近目标查询、稳定并列顺序、实体/地形先后、火把瞄准特殊规则、冻结冲量与现有小鸡命中链路；玩家非法伤害先拒绝、一次性死亡、死亡后拒绝直接操作且旧子弹续行。
- 导航：L/U 墙、封闭区域、不同半径、窄道/圆角、对角约束、水域代价、真实连接段、阻挡目标替代、矿石非致命伤与破坏、直接改图 invalidate、取消、替换、预算耗尽和持续高优先级替换下的低优先级等待。
- 角色：真实 Player 翻滚不穿过尸群；分离不进墙；固定玩家不被后置修复挪动；dying 阻挡至移除；动态拥堵不产生静态寻路风暴。
- 感知：较旧声音稍后可闻、已听逐事件去重与清理、未知来源排除、墙后枪声只调查、持灯目标暴露仍经过视锥/LOS/确认、近身半角、小鸡兼容、丢失视觉不读实时玩家位置。
- 战斗：扇形与玩家圆的真实相交、从攻击者中心量程、前摇躲避、背面/隔墙落空、命中时刻跨越只发一次、多敌保护、硬直冷却期间仍逐发扣血、不缩短恢复期限、致命伤取消攻击/导航、一次尸体收尾。
- 生存：非叠层且不刷新感染计时、实际伤害才判感染、已感染不抽取多余随机数、保留余量/大 delta 算术扣血、死亡/治疗/重置清理、非法数量/溢出拒绝、疫苗使用原子性、不回血、不无效耗库存。
- 交互：肉块/疫苗混排、距离先于物品优先级、按住锁定、范围内移动不中断、一次按住一件、触觉剪影交互、失焦清理及原有拾取回归。
- 时间：Shambler 与 Runner 都以 30/60/144 FPS 验证连续确认、攻击命中、硬直、死亡与搜索；DOT、拾取与导航节拍另有同帧率用例。误差不超过一个模拟步，无重复/遗漏命中和死亡事件。

### 浏览器

既有完整链包括光照、火把、地形短阴影、碰撞、移动、边界、相机、鼠标枪械、武器 HUD、拾取、旧迷雾、三层感知、感知连续性、开发/生产入口、挖矿、水域、F2、圆角地形、玩家动画和小地图。代表输出包括 63 组碰撞、156 组圆角栅格、120 组 F2 检查，以及水域三档 DPR 的 30/60/144 FPS 与真实鼠标水中弹道。

丧尸专项覆盖：

1. DPR 1/1.25/2 默认两类生成、追踪及程序化形象。
2. 360×640、640×360、1280×720 下两剂来源、E 单次拾取、R 与 V 输入优先级、治疗不回血及 HUD。
3. F2 下子弹、位置、感染、武器、敌人记忆/状态/路径、导航、噪声年龄、尸体收尾及绘制地形高亮快照不变；音频处于暂停状态；E/V 长按不补发。
4. 死亡旧子弹继续，Enter 返回菜单不连开，重新开始使用新实例；旧敌人/噪声/库存清空，无准星或面板 DOM 残留。
5. 种子 8 的真实 Runner 近战按默认 18% 概率感染，随后真实子弹击杀、地图 E 拾取和 V 治疗；死亡未增加疫苗。
6. G 同帧暴露；隐藏敌人不点亮准星；缩放 1.2、相机震动和墙边部分遮挡；墙顶没有身体像素，反复绘制不推进姿态。

音频位置、循环/一次性声部的暂停/续播、淡出冻结和完整停止还通过可控 Audio 测试验证，未把逻辑噪声误当成真实采样播放。

## 5. 性能环境与方法

- OS：win32 10.0.22631。
- CPU：12th Gen Intel(R) Core(TM) i5-12600KF，16 逻辑处理器；内存约 31.9 GiB。
- Node：v24.19.0；外部 Playwright 1.64.1；Headless Chromium 156.0.8078.4。
- 浏览器渲染器：`ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device (Subzero) (0x0000C0DE)), SwiftShader driver)`。这是软件渲染环境，不能据此推断实机 GPU 帧率。
- 固定地图：40×30 个 50 像素瓦片、干地和一段长墙；玩家中心初始 (800, 750)，种子 424242；视口 1280×720；DPR 1 与 2。
- 每档独立场景，预热 1 秒后记录 10 秒墙钟时间；用固定 1/60 游戏时间步推进相同 WASD 方形路线，并每 .75 个游戏秒发送一次玩家枪声事件。
- 只在性能夹具把玩家最大生命设为 1,000,000，避免死亡使追击工作量提前下降；敌人全部保持活动，生成数量每档均等于要求。疫苗仍为 2，小鸡仍为 60。
- AI/导航 = 敌人感知/行为/跟随准备 + 导航调度 CPU；移动和分离单独记录。整帧 CPU = 场景 update + draw 提交时间；rAF 间隔另列。浏览器计时粒度会使很小的数显示 0，不能解释为完全零开销。
- 初次探索采样与验证进程存在重叠，已丢弃；以下数据为全部验证结束后独立重跑的完整 10 档。
- GPU 时间、GC 时间：不可用。没有用 frame CPU 或堆大小反推这两项。

### 目标判定与边界

- AI/导航 2ms：默认 4 只在 DPR 1/2 的 P95 均为 .3ms，通过；20 只为 1.1–1.3ms。50 只为 2.0–2.3ms，100 只为 3.2–3.4ms，压力档未全部达到该目标。
- 整帧 16.67ms：本环境未达到。0 只对照 P95 为 22.8/54.3ms，4 只为 23.2/54.1ms（DPR 1/2）；不能把整帧超标全归到敌人，也不能由这组软件渲染数据宣称实机 60 FPS。
- 10 秒窗口在 rAF 结束边界存在至多一个长帧的收尾偏差，原始 samplingMs 保留实际记录。
- 固定场景样本没有覆盖任意地图的最坏几何耗时；最坏工作量依靠有界调度、明确取消及 Node 障碍/预算用例验证。

## 6. 修复和未通过项

最终功能断言没有未通过项。实施中发现并修正：较旧可闻事件被最大 ID 漏过滤；近身视锥未应用；击退默认干地限制；角色只碰地形；路径收尾集中计算、端点下界及高优先级替换的饥饿边界；死亡后的动作入口与 Enter 边界。

旧浏览器夹具曾直接替换 map，导致新加入的碰撞/导航仍引用原地图，或者把随机疫苗计入只期望一个肉块的断言。相关场景改为构造时注入固定地图和显式空遭遇，保留全部既有断言；专用丧尸夹具同时验证真实默认敌人/疫苗闭环。没有给生产默认关闭新系统来获取通过结果。F2 测试保留原恢复后进度断言，并增加暂停不推进的断言。

开发服务器忽略 tests 目录的文件监听；修改内联夹具后旧 HTML proxy 可能仍缓存旧脚本。最终验证在重启后的服务器执行，功能修复期间的 HMR 导航中断未计为通过。

仍未达到/不可用的项目明确保留：本环境整帧 16.67ms 目标；部分压力档的 2ms AI/导航目标；GPU/GC 时间。当前没有丧尸音频采样，因此实际采样静默，世界噪声与模糊提示已验证。这些限制不被标为已通过的性能或素材验收。
