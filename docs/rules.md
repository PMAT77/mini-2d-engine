# 规则与数值

> 本文把设计支柱写成可实现、可测试的规则。
> 数值为首版初值，需要在垂直切片中验证，不作为承诺。

## 1. 单位与约定

| 项 | 值 |
| --- | --- |
| 1 格 | 50 世界像素 |
| 玩家移速 | 3.2 格/秒（160 像素/秒） |
| 玩家碰撞半径 | 0.5 格 |
| 手电视距 | 8 格 |
| 迷雾半径 | 8 格 |
| 逻辑步长 | 按 delta 推进，测试固定 1/60 秒 |

坐标统一用世界像素。涉及距离的规则同时标注格数，方便换算。

## 2. 光照 E

### 公式

E(p) = clamp(E_amb + Σ E_i(p), 0, 1)

E_i(p) = I_i × (1 − d_i / R_i)^1.5 × O_i(p)

- I_i：光源强度。
- d_i：光源到 p 的距离。
- R_i：光源半径。
- O_i：遮挡系数。0 为完全遮挡，1 为无遮挡；沿光线取 3 个采样点，取平均。

环境光 E_amb 默认 0.35。关卡可以覆盖，例如地下室取 0.10。

### 分级

| 等级 | E 范围 | 表现 |
| --- | --- | --- |
| 黑暗 | < 0.20 | 只能看见轮廓 |
| 微光 | 0.20～0.50 | 可辨认形状与高光 |
| 明亮 | 0.50～0.80 | 可识别细节 |
| 强光 | > 0.80 | 暴露，获得命中辅助 |

### 用途

- 敌人视觉的发现速度。
- 战利品细节与颜色辨识。
- 玩家 HUD 的隐蔽提示。

## 3. 噪声 N

### 事件结构

```ts
type NoiseEvent = {
  x: number;
  y: number;
  radius: number;    // 最大传播格数
  loudness: number;  // 0～1
  tag: "step" | "sprint" | "water" | "shot" | "reload" | "loot" | "breach" | "throw";
  ttl: number;       // 秒
};
```

### 传播

L(d) = loudness × max(0, 1 − d / radius) × W

W = 0.7^k。k 为路径穿过的墙格数，最多计 3 格。

听觉阈值 0.15。低于阈值的事件不产生怀疑。

### 事件表

| 事件 | 半径 | 强度 | 触发 |
| --- | --- | --- | --- |
| 慢走一步 | 3 格 | 0.5 | 每 0.32 秒 |
| 奔跑一步 | 8 格 | 0.8 | 每 0.24 秒 |
| 涉水一步 | ×1.6 | +0.1 | 同上 |
| 开枪 | 25 格 | 1.0 | 每次射击 |
| 换弹 | 4 格 | 0.4 | 开始与结束 |
| 开箱 | 6 格 | 0.6 | 交互期间每 0.5 秒 |
| 破墙 | 15 格 | 0.9 | 每次命中 |
| 丢照明棒 | 3 格 | 0.3 | 落地 |

脚步按步距 26 像素触发，不按帧触发。

## 4. 敌人感知

### 视觉

rate = (0.6 + 2.4 × E) × (1 − d / R)^1.2 × A

- R：视距。巡逻兵 12 格。
- A：角度系数。中心 1.0，边缘 0.6。
- 结果单位为 detection/秒。

detection 上限 1。目标离开视野后每秒衰减 0.5。

阈值：0.5 进入怀疑，1.0 进入交战。

### 听觉

- 收到 L ≥ 0.15 的事件，记录声源位置。
- suspicion += 0.6 × L × 听觉系数。
- 听觉系数：巡逻兵 1.0，猎犬 1.6，重甲兵 0.8。
- suspicion 每秒衰减 0.2。
- suspicion ≥ 1，或 2 秒内收到第二个事件，进入搜索。

### 记忆

- 最后已知位置保留 8 秒。
- 搜索半径 6 格。先走向声源，再绕圈。
- 搜索超时回到巡逻，警戒降一级。

### 状态机

| 状态 | 进入条件 | 退出条件 |
| --- | --- | --- |
| 巡逻 | 初始 | 怀疑 |
| 怀疑 | detection ≥ 0.5，或收到噪声 | 搜索、交战、回巡逻 |
| 搜索 | suspicion ≥ 1，或失去目标 | 交战、8 秒超时 |
| 交战 | detection = 1 且有视线 | 失去视线 3 秒 |
| 增援 | 交战 1.5 秒后 | 10 秒后增援抵达 |

状态切换有 0.2 秒前摇，给玩家反应时间。

## 5. 玩家状态

| 项 | 值 |
| --- | --- |
| 生命 | 100 |
| 护甲 | 0～50，减伤 30% |
| 体力 | 100，消耗与恢复沿用现有配置 |
| 负重阈值 | 40 / 60 |

负重惩罚：

| 负重 | 效果 |
| --- | --- |
| ≤ 40 | 无 |
| 40～60 | 移速 −10% |
| > 60 | 移速 −25%，不能奔跑 |

流血：单次受伤 ≥ 20 时触发，每秒 −1 生命，持续 4 秒。移动会留下血迹，存在 20 秒。猎犬可在 15 格内追踪血迹。

治疗：绷带 3 秒回 30；医疗包 6 秒回 60。治疗期间移动会中断。

## 6. 战斗

### 玩家

沿用现有武器数值：手枪 10 伤害，冲锋枪 16 伤害。背后攻击 ×1.5。

### 敌人

| 敌人 | 生命 | 攻击 | 说明 |
| --- | --- | --- | --- |
| 巡逻兵 | 60 | 8 × 3 点射 | 间隔 0.35 秒 |
| 猎犬 | 30 | 20 撕咬 | 扑击前摇 0.3 秒 |
| 重甲兵 | 200 | 25 近距射击 | 正面减伤 80% |
| 探照灯 | 20 | 无 | 提供光照与警戒 |

敌人之间不互相伤害，爆炸与陷阱除外。

### 死亡

玩家生命归零立即结算，不进入倒地状态。

## 7. 撤离与结算

- 明撤离点：交互 6 秒。
- 暗撤离点：交互 10 秒，需要钥匙卡或恢复供电。
- 交互期间受伤会中断，进度回退 20%。
- 撤离成功结算：战利品价值、用时、击杀数、被发现次数。
- 撤离失败：丢失携带物。仓库、蓝图与情报保留。

## 8. 性能与可读性上限

| 项 | 上限 |
| --- | --- |
| 同屏敌人 | 6 |
| 同屏动态光源 | 12 |
| 同屏噪声环 | 8 |
| 血迹贴花 | 64 |

超出上限时，优先保留离玩家最近的实例。

## 9. 测试口径

- 所有随机使用可注入种子，测试固定种子。
- 光照、噪声、感知提供纯函数版本，便于单元测试。
- 验收用例：
  - 关灯慢走在 3 格外不被听见。
  - 开枪在 25 格内必被听见。
  - 背后攻击伤害为 1.5 倍。
  - 撤离被打断，进度回退 20%。
