# 手雷与烟雾弹

新局在出生点附近的可达干地生成两枚手雷、两枚烟雾弹，按住 E 拾取。在背包“投掷物”分类中右键握持、丢弃或绑定快捷栏 1–4，也支持拖出背包丢弃。

数字键握持，按住右键瞄准；手雷按下左键开始 4 秒引信，松开左键投出。拉环后不能切换、翻滚、治疗或拾取，握满时间会在手中爆炸。烟雾弹没有提前计时，首次触地开始排烟。投出后自动握持下一枚，用尽时恢复之前的武器。

背包只锁定角色输入，世界、引信、烟雾、伤害和既有动作继续推进。ESC 关闭当前面板并暂停，再按 ESC 或点击“继续游戏”恢复；F2 和失焦同样暂停世界。恢复后重新按下并松开左键才能投出已拉环手雷。普通丢弃不会启动引信，已经投出的弹体不可拾取。

首版物理使用平面圆形连续碰撞和独立高度，实体墙不可越过；落地弹跳、撞墙反弹，水面强阻尼且不弹跳。轨迹预览使用真实模拟，并在不可观察区域截断。手雷按距离衰减伤害角色和可破坏地形，沿用矿物掉落；硬墙及本次爆炸前的地形阻挡冲击。爆炸击退敌人、震动镜头，玩家不产生击退位移。视野外可听爆炸使用偏暖双层涟漪，屏幕外投影为边缘短弧；非规则烟团影响双方视觉，近处角色仅留下模糊剪影，声音、子弹及移动不受阻挡。玩家在烟内仍可按住 E 拾取 70 px 内无墙阻挡的掉落物，不显示额外物品细节。

调参入口：`src/throwables/ThrowableConfig.ts`。场景生成量：`GameSceneOptions.encounters.grenades/smokeGrenades`。数量由 `ConsumableInventory` 唯一持有，准备动作预留一枚，投出、手中爆炸或死亡掉落时提交消费；背包和 HUD 只读取快照。

素材提示词与来源：`public/assets/images/throwables/SOURCE.md`；爆炸音效是本地程序合成的短促低频与衰减噪声，来源记于 `public/audio/throwables/SOURCE.md`。

验证：`npm test`、`npm run typecheck`、`npm run build`、`npm run test:throwables-browser`。浏览器脚本读取 `PLAYWRIGHT_MODULE` 和 `TEST_BASE_URL`，默认使用本地 5182 端口。

快捷栏耗尽后保留暗淡图标和数量 0，再拾取自动恢复绑定；不会自动装备。悬浮快捷栏可拖动：移入其他槽位交换或移动，拖出释放或右键解绑，解绑不丢弃库存。绑定只保留本局。切换武器、空手或投掷物中断换弹/装填，已经逐发入匣的子弹保留。

B 打开/关闭背包；面板外按下鼠标立即关闭，点击不穿透开枪。背包内拖出释放仍为丢弃物品。ESC 直接进入暂停。背包、调试和暂停面板使用短过渡，支持系统减少动态效果偏好。

悬浮圆形小地图滚轮缩放，覆盖半径为 300 / 450 / 600 / 900 / 1200 px（默认 600），外框大小不变；地图外滚轮切枪。

每张正式地图按种子生成 1–2 个交易站，使用用户提供的 `ic_terminal_console.png`。底座阻挡移动和弹体，纳入导航；靠近 90 px、无墙阻挡时提示 T。按 T 显示“交易功能暂未开放”，当前只提供场景与交互入口。`GameSceneOptions.encounters.tradingStations` 可设 0–2，测试空场景设 0。
