# 生存状态图标

2026-11-01 使用 ImageGen 生成的原创透明 PNG，每张只包含中心图形。

- `hunger.png`：带骨肉块，饥饿/饱食状态。
- `thirst.png`：带留白高光的水滴，饮水状态。
- `infection.png`：三瓣生物危害符号，感染状态。

风格为灰白墨色、轻微磨损的克制手绘生存风。分段环、状态着色、局部暗底与 V 提示由 `PlayerStatusHud` 绘制，未烘焙到素材中。

设计参考《漫漫长夜》的图标化 HUD，以及《DayZ》统一轮廓和小尺寸辨识度的原则；未提取或复制游戏素材。
