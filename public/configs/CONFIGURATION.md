# 玩家配置

编辑 `playerConfig.json` 并刷新页面后应用。文件是完整示例，不需要额外模板。配置加载器会缓存当前页面内已获取的配置；游戏不监听文件变化、不自动热更新。

所有分组和字段均可省略，缺省值如下，与玩家类和随项目提供的 JSON 一致。

| 分组 | 字段 | 默认值 | 含义 |
| --- | --- | --- | --- |
| base | size | 49 | 主体直径；默认碰撞半径为 size / 2，不随外观和呼吸变化 |
| base | maxHealth | 100 | 血量上限；修改上限时保留当前血量比例 |
| base | maxSpeed | 400 | 最大移动速度，像素/秒，可为 0 |
| base | accel | 4000 | 旧配置兼容字段，不再控制玩家移动 |
| base | decel | 1200 | 旧配置兼容字段，不再控制玩家移动 |
| base | nonlinearFactor | 0.5 | 旧配置兼容字段，可为 0，不再控制玩家移动 |
| base | rotationSpeed | 12.5664 | 模型跟随移动方向的最大旋转速度，弧度/秒；不控制射击指针 |
| base | rotationStrategy | auto | 模型移动转向策略；auto 最短路径，cw 顺时针，ccw 逆时针；不影响射击指针 |
| movement | startSpeedRatio | 0.7 | 按下移动键立即获得的速度比例，范围 0–1 |
| movement | startupDuration | 0.08 | ease-out 起步时长，秒；0 表示立即满速 |
| movement | turnDamping | 0.012 | 转向阻尼的时间常数，秒；0 表示即时转向，反向始终立即响应 |
| movement | stopDuration | 0.2 | 松键后的最大收尾时长，秒；实际不超过本次连续按键时长，以 smoothstep 曲线先缓减速再收住，设 0 恢复立即停步 |
| sprint | speedMultiplier | 1.6 | 疾跑倍率，必须大于 1，与移速道具及地形相乘 |
| sprint | rampDuration | 0.16 | 从常速升至疾跑速度的时长，秒；使用 smoothstep 曲线，0 表示立即提速 |
| sprint | maxStamina | 100 | 体力上限 |
| sprint | drainPerSecond | 25 | 实际疾跑移动时每秒消耗的体力 |
| sprint | regenPerSecond | 35 | 非疾跑时每秒恢复的体力 |
| sprint | regenDelay | 0.6 | 最后一次消耗到开始恢复的间隔，秒，可为 0 |
| sprint | restartThreshold | 0.15 | 耗尽后的恢复门槛，范围大于 0 且不超过 1；还须松开过 Shift |
| animation | breathingAmplitude | 3 | 待机呼吸幅度，百分比，可为 0 |
| animation | breathingSpeed | 2 | 待机呼吸速度，可为 0 |
| shooting | fireRate | 0.2 | 每发之间的间隔，秒/发，越小射速越高 |
| shooting | damage | 10 | 基础子弹攻击力，与伤害道具增益叠加 |
| shooting | aimTurnDuration | 0.15 | 相邻方向连续切换时的指针滑动时长，秒；0 表示立即定位 |
| shooting | aimContinuityWindow | 已停用 | 旧配置兼容字段，提供时仍须为正有限数；持键瞄准不再超时 |
| shooting | bulletSpeed | 800 | 子弹速度，像素/秒 |
| bulletWaterDrag | shallow | 0.4 | 浅水中每秒扣除的发射速度比例，可为 0 |
| bulletWaterDrag | water | 0.8 | 普通水中每秒扣除的发射速度比例，可为 0 |
| bulletWaterDrag | deep | 1.6 | 深水中每秒扣除的发射速度比例，可为 0 |
| bulletWaterDrag | ultraDeep | 3.2 | 极深水中每秒扣除的发射速度比例，可为 0 |
| shooting | maxShootingTime | 3.5 | 持续射击的热量容量，以秒计 |
| shooting | maxOverheatCooldownTime | 1 | 过热后的冷却时间，秒 |
| ui | fadeSpeed | 5 | 武器热量／过热冷却圆环的淡入淡出速度 |

除表中标明可为 0 的字段外，数值必须是大于 0 的有限数。未知分组、未知字段、错误类型或旋转策略都会导致加载失败；整个配置验证通过后才会应用，避免只更新一部分参数。

射击指针位于角色外侧的隐形圆轨道上。同次射击中，相邻方向（相差 45°）始终沿最短圆弧线性滑动，默认 150 毫秒到位，持键时间没有限制；新目标立即接管当前过渡。首次输入及跨方向跳变直接定位。重复按键不重启过渡；松开、方向相互抵消或失焦后立即隐藏并清除连续状态。过热不影响瞄准。模型只跟随移动速度方向，静止时保留最后朝向，移动与模型转向不改变指针的世界角度。子弹从角色中心沿指针当前插值角度射出，不量化为八方向，已发射子弹不随指针转弯。保留默认 0.2 秒射击间隔，不额外补弹，因此不是每次过渡都会产生子弹。指针与轨道不参与碰撞，生命／体力条和热量环位于指针活动范围之外。

地图每格为 50 像素；将角色尺寸调大可能无法通过狭窄通道，极端尺寸可能找不到出生位置。移动和旋转检查中间姿态，子弹检测整段路径；运动求解预算耗尽时停止在最后合法位置。

## 碰撞形状

玩家主体固定为居中圆形。可选顶层 `collider` 分组省略时使用半径 `0.5`；以 `base.size` 为一单位，默认物理半径为 24.5 像素。`center` 可省略，提供时必须为 `[0,0]`。

圆形：`"collider": {"type":"circle","radius":0.5,"center":[0,0]}`，`center` 可省略。

玩家配置不接受多边形、复合体或偏心圆；半径必须为正有限数值。非法形状会使整个配置加载失败，应用主体尺寸后重新检查出生位置。引擎其他实体仍可通过 `Entities.setCollider()` 设置凹多边形及复合形状，在碰撞验收页中可切换查看。

水域根据圆形主体覆盖比例渐进缓速，半身入水时速度系数为 0.75，全身入水时为 0.5。皮肤、武器及装饰不参与碰撞、缓速或拾取检测。呼吸仅在绘制时缩放图片，动画放大或缩小时主体半径始终不变。

玩家使用起步速度比例与轻微方向阻尼，转向不损失速度、不重置起步，反向立即响应。`turnDamping` 默认 0.012 秒，可调为 0 关闭，或小幅提高来试手感。松键后以 smoothstep 曲线收尾，时长取本次连续按键时长与 `stopDuration`（默认 0.2 秒）的较小值；短按不会触发完整惯性，持续移动后常速满速收尾滑行约 40 像素。重新输入立即接管并重新计算本次按键时长，收尾仍受碰撞和地形约束、不扣体力。设为 0 可恢复立即停步。调低 `startSpeedRatio` 或提高 `startupDuration` 会加重起步感，建议先保持默认值。旧 `accel`、`decel`、`nonlinearFactor` 仍可读取，但不再参与玩家移动。

按 Shift 后用 `rampDuration`（默认 0.16 秒）从常速平滑升到疾跑速度，转向和反向不重置升速过程。松开 Shift 立即回到常速，再次按下会重新升速；升速期间正常消耗体力。默认满体力可疾跑 4 秒，恢复延迟结束后从空到满约 2.9 秒。耗尽后持续按住 Shift 不会自动续跑；站立和完全受阻时不扣体力，滑墙移动时正常扣除。修改体力上限会保留剩余体力比例；`getMaxSpeed()` 返回含道具增益的基础最大速度，疾跑倍率独立计算。可通过 `getStamina()`、`getMaxStamina()`、`getIsSprinting()` 查询当前状态。

降低 `fireRate` 会提高射速，增加 `maxShootingTime` 会延长连续射击时间。这些参数用于手感与平衡调节，不应作为渲染性能优化手段。

生命值默认 100，基础子弹伤害默认 10，分别通过 `base.maxHealth` 与 `shooting.damage` 配置。省略字段的旧文件继续使用默认值。

## 游戏内调试

进入游戏后，点击右上角“调试 · F2”或按 F2 打开角色调试侧栏，按 Escape 收起。开发版及打包版都提供入口。游戏继续运行；焦点在面板内时屏蔽角色按键，点击游戏画面后恢复控制。

数字输入按回车或失焦应用，错误值会显示提示且不改变属性。面板射速单位为“发/秒”，配置文件仍为“秒/发”；例如界面 5 发/秒对应 `fireRate: 0.2`。移动手感直接调起步时长、停止滑行时长等有效参数，旧 `accel`、`decel` 不作为面板调节项。快速移速通过基础移速与倍率计算。

“攻击”分组的“指针滑动时长”控制相邻方向切换时的滑动速度，对应 `shooting.aimTurnDuration`，默认 0.15 秒。数值越小滑动越快，设为 0 则瞬间定位；不改变武器射速和角色模型转向。“恢复初始参数”同时还原此项。

“子弹水体阻力”分组独立调节四档水深的减速强度，单位为“发射速度 %/秒”，默认依次为 40、80、160、320；数值越小阻力越弱，0 关闭该水深的阻力。配置文件 `bulletWaterDrag` 使用比例，例如界面 40 对应 `shallow: 0.4`，表示每秒扣除发射速度的 40%。完全处于单一水深时，从原速到停止分别需 2.5、1.25、0.625、0.3125 秒。按子弹与水体的实际覆盖比例加权，只对水中开火的子弹生效；离水保留剩余速度。每颗子弹在发射时复制这组参数，修改只影响后续发射；“恢复初始参数”还原四项，本次调试不写回 JSON。

当前血量、体力、热量与过热剩余时间可独立设置；容量变化保留剩余比例。热量设为 100% 会触发过热，过热剩余时间设为 0 或点击“清除过热”恢复射击；主动补充体力会清除耗尽锁定。面板显示基础参数，已有道具增益继续叠加，有增益时显示实际值。实际移动还会受到水域与碰撞约束。

“恢复初始参数”恢复本次场景加载后的配置，并回满血量、体力、清除热量，不移除道具增益。调试改动仅在当前页面运行中生效，不写回 JSON，刷新页面后还原。

“角色光照”分组可调光圈半径（像素，允许为 0）和光照强度（0–2，0 关闭角色照明）。修改即时作用于跟随角色的真实光源；半径控制照射范围，发光体尺寸与环境光维持原有设置。“恢复初始参数”同时还原本次场景加载时的角色光照，离开再进入同一场景也保留这个还原基准。光照由场景管理，仅本次运行生效。
